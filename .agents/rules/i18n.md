# Mandatory Multi-Language (i18n) Requirement

## Rule
Whenever adding, modifying, or creating any user interface, component, page, form, modal, notification, error message, or label in this repository, you **MUST** support multiple languages: **English (`en`)** and **Vietnamese (`vi`)**.

## Implementation Standards
1. **Never hardcode raw text strings directly in templates or TypeScript logic without localization.**
2. **Translation Service**: Use `TranslationService` (`src/app/core/services/translation.service.ts`).
   - In code: `this.translation.t('auth.signIn')` or reactive `computed(() => this.translation.t('nav.dashboard'))`.
3. **Translation Pipe**: Use `TranslatePipe` (`src/app/shared/pipes/translate.pipe.ts`).
   - In template: `{{ 'common.search' | translate }}` or `{{ 'common.unreadNotifications' | translate:{ count: 3 } }}`.
4. **JSON Dictionaries (Single Source of Truth)**: When introducing new text, **ALWAYS** add both the English (`en`) and Vietnamese (`vi`) translations into:
   - `src/assets/i18n/en.json` and `src/assets/i18n/vi.json`
   - `public/i18n/en.json` and `public/i18n/vi.json`
   `TranslationService` automatically imports and flattens these JSON files into dot-notated keys (e.g. `'common.search'`, `'auth.signIn'`).
5. **Language Switcher**: Ensure the UI connects to `LanguageSelectorComponent` and tests correctly in both `en` and `vi`.
